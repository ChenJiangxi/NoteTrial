## 1. 产品愿景

### 1.1 核心价值主张

**一句话定位**：小红书内容创作的「AI 副驾驶」— 从灵感到爆款的全流程陪伴

**解决的核心问题**：
- ❌ 创作者发帖前无法预知效果，试错成本高
- ❌ 内容优化依赖经验，缺乏数据支撑
- ❌ 爆款规律难以总结和复用
- ❌ 批量创作效率低，难以规模化

**NoteTrial 的解决方案**：

| 问题 | NoteTrial 方案 |
|------|---------------|
| 不知道哪个版本更好 | A/B CrowdTest 模拟真实用户反馈 |
| 内容缺乏平台适配 | 小红书 MCP 实时校准 |
| 爆款规律难总结 | 自动学习高赞内容模式 |
| 批量创作效率低 | 全自动生成-发布-学习闭环 |
| 找素材费时间 | 素材库统一管理 + 智能推荐 |
| 风格不稳定 | 历史发帖学习，保持个人风格 |

### 1.2 目标用户

| 用户类型 | 核心诉求 | 适用模式 |
|---------|---------|---------|
| 个人创作者 | 提升单篇爆款率 | 人机交互模式 |
| MCN/运营团队 | 批量账号内容生产 | 自动学习模式 |
| 品牌商家 | 低成本内容营销 | 两种模式结合 |
| 独立开发者 | 产品推广 | 人机交互模式 |

### 1.3 产品差异化

| 竞品类型 | 功能 | NoteTrial 优势 |
|---------|------|---------------|
| AI 写作工具 | 只能生成内容 | 生成 + 模拟测试 + 效果追踪 |
| 数据分析工具 | 事后分析 | 事前预测 + 事后学习 |
| 自动发布工具 | 批量发布 | 智能生成 + 自适应优化 |
| 素材管理工具 | 仅存储 | 智能推荐 + 风格学习 |

## 3. 核心功能模块

### 3.1 人机交互模式

```
┌─────────────────────────────────────────────────────────────┐
│                      人机交互模式                             │
├─────────────┬─────────────────────┬─────────────────────────┤
│  对话面板    │    内容编辑区        │    CrowdTest 面板       │
│             │                     │                         │
│ - 任务描述   │  Version A          │  Persona 投票           │
│ - AI 建议    │  ──────────         │  - 大学生小美 (收藏党)   │
│ - 优化指导   │  标题 / 正文 / 标签   │  - 职场丽丽 (点赞狂)    │
│             │                     │  - 宝妈小芳 (评论达人)   │
│             │  Version B          │  - ...                  │
│             │  ──────────         │                         │
│             │  标题 / 正文 / 标签   │  统计结果 & 置信度       │
│             │                     │  诊断建议               │
└─────────────┴─────────────────────┴─────────────────────────┘
```

**核心流程**：
1. 用户通过对话描述创作意图
2. AI 生成 A/B 两版内容
3. 用户可编辑修改
4. 启动 CrowdTest，模拟用户投票
5. 获得统计结果和优化建议

```

│  └────────┘ └────────┘ └────────┘ └────────┘              │

├─────────────────────────────────────────────────────────────┤
│  效果优化建议:                                               │
│  • 标题 16-20 字效果最好                                     │
│  • 高效果标签: 探店、必吃、本地人                             │
├─────────────────────────────────────────────────────────────┤
│  AI生成时将应用以下风格:                                      │
```

**学习维度**：

| 维度 | 分析内容 | 应用场景 |
|------|---------|---------|
| 语气风格 | casual/cute/professional/neutral | 生成提示词 |
| emoji密度 | 统计使用比例 | 控制生成时emoji量 |
| 段落风格 | 短/中/长/混合 | 控制段落结构 |
| 标点风格 | 正常/感叹/简约 | 匹配用户习惯 |
| 常用标签 | 高频标签提取 | 自动补充标签 |
| 效果洞察 | 高赞内容特征 | 优化生成策略 |

### A. Persona 定义

| Persona | 特征 | 行为模式 |

| 宝妈小芳 | 28-35岁，育儿相关，爱评论 | 共鸣内容 → 评论 |
| 数码宅男 | 20-28岁，理性分析，看数据 | 专业内容 → 关注 |
| 文艺青年 | 22-30岁，追求审美，爱分享 | 美学内容 → 分享 |

### B. 关键指标

| 指标 | 计算方式 | 说明 |
|------|---------|------|
| 爆款率 | 收藏数 > 100 的笔记占比 | 衡量内容质量 |
| 互动率 | (点赞+收藏+评论) / 浏览量 | 衡量内容吸引力 |
| 风格一致性 | 风格分析匹配度 | 衡量内容稳定性 |
| AI 检测率 | 被标记为 AI 的比例 | 需要尽量降低 |
